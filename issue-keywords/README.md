# 이슈 키워드 탐지기

지금 뜨는 검색어 중에서 "방법·일정·결과·조회"처럼 **사람들이 찾아보고 클릭하는 꼬리 검색어**가 붙은 것을 골라
블로그 글감 후보로 보여줍니다. API 키가 필요 없습니다.

## 실행

```powershell
python issues.py              # 리포트 (마크다운)
python issues.py --summary    # 휴대폰 알림용 한 줄
python issues.py --hours 6    # 시작한 지 6시간 이내 키워드만
python issues.py --json       # 원자료
python expand.py "청년도약계좌" # 주제 하나 → 실제 검색어 목록 (블로그 키워드)
```

한 번 도는 데 1분쯤 걸립니다 (자동완성을 키워드마다 네 번씩 물어봐서).

## 어디서 가져오나

| 수집처 | 무엇을 | 비고 |
|---|---|---|
| 구글 트렌드 실시간 RSS (한국) | 뜨는 검색어, 검색량 대략치, 시작 시각, 관련 뉴스 | 검색량은 구글 기준. 네이버 검색량은 없음 |
| 시그널(signal.bz) | 실시간 이슈 10개와 순위 변화 | 네이버 쪽 흐름 참고용. 문장형 키워드가 많음 |
| 네이버·구글 자동완성 | 키워드 뒤에 붙는 검색어 | "투표방법", "재방송", "조회" 등을 여기서 찾음 |

## 점수

검색량(로그) + 신선도(막 시작할수록 가산, 10시간 뒤 0) + 시그널 순위 + 꼬리 검색어 개수(최대 5개) − 사건·사고.
사건·사고성 키워드(사망, 폭발, 참사 등)는 광고가 잘 안 붙고 다루기도 조심스러워서 크게 깎습니다.

꼬리 검색어 목록은 `INTENT_WORDS`, 사건·사고 단어는 `TRAGEDY_WORDS`에서 고칩니다.

## 한계

- 네이버 실시간 검색어는 서비스가 없어져서 직접 못 봅니다. 시그널과 네이버 자동완성으로 대신합니다.
- 자동완성은 "요즘 많이 찾는" 검색어라서, 오늘 이슈와 무관한 오래된 꼬리 검색어가 섞일 수 있습니다 (예: "선거" → "지방선거 결과").
- 글을 쓰기 전에 반드시 공식 발표 원문으로 날짜·방법을 확인하세요. 틀린 정보는 이탈률을 올려 순위를 떨어뜨립니다.
