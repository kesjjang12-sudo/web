# 포장재 영업 트리거 감지기

골판지·스티로폼·아이스팩·부자재 B2B 영업용. "지금 문제없어요"라는 답을 피하려고,
**거래처를 바꿀 만한 순간**을 찾아서 매일 아침 노션에 알려준다.

## 보는 것

| 트리거 | 무엇을 | 어디서 |
|---|---|---|
| 시즌 | 설·추석 45일 전, 여름 보냉 성수기, 김장철, 연말 택배, 어버이날 | 코드 안 캘린더 (`FIXED_SEASONS`, `HOLIDAYS`) |
| 뉴스 | 원지·스티로폼·포장재 가격 인상, 공장 화재·품절, 택배 물량 급증 | 구글 뉴스 RSS |
| 신규 업체 | 최근 7일 안에 허가받은 식품제조·즉석판매제조·식육포장 등 업체 | 식품안전나라 I2500 (`new_businesses.py`) |
| 재연락 | "지금은 괜찮다"고 한 곳의 다음 연락일 | 노션 `영업 리드` 표 (매일 아침 루틴이 조회) |

뉴스는 제목에 **품목 단어**(골판지·원지·스티로폼 등)와 **상황 단어**(인상·품절·급증 등)가
둘 다 있어야 통과한다. "박스" 같은 짧은 단어는 엑스박스·박스피 기사가 걸려서 뺐다.

## 실행

```bash
python3 triggers.py                  # 오늘 기준 (한국시간), 최근 7일 뉴스
python3 triggers.py --days 30        # 뉴스 기간 늘리기
python3 triggers.py --date 2026-10-20  # 특정 날짜 기준 시즌 확인
python3 triggers.py --json           # 원자료
```

표준 라이브러리만 쓴다. 설치할 것 없음.

## 해마다 고칠 것

- `HOLIDAYS`: 음력 명절 날짜. 2028년 추석까지 들어 있다.

## 신규 업체 감지 (`new_businesses.py`)

```bash
FOODSAFETY_API_KEY=발급받은키 python3 new_businesses.py --region 서울,경기,인천
```

- 키: 식품안전나라 > 데이터활용서비스 > 인증키 신청 (무료). 없으면 샘플 키로 업종당 5건만 받는다.
- `TARGET_REGIONS` 환경변수나 `--region`으로 영업 지역만 남긴다 (주소 앞부분 일치).
- API가 변경일 필터(`CHNG_DT`)를 7일 전까지만 받아서 매일 돌리는 전제다. 업종·날짜 필터는 `&`로 잇는다.
- 공개 데이터라 대표자·전화번호가 비어 있는 경우가 많다. 업체명으로 검색해서 찾는다.
- 지방행정 인허가(LOCALDATA)는 2026년 4월에 닫혀 공공데이터포털로 옮겨갔고, 공공데이터포털·공정위는
  해외 서버 접속을 막아서 쓰지 않는다. 식품안전나라는 클라우드에서도 열린다.

## 주의

  홈페이지에서 이메일을 자동 수집하는 것은 제50조의2 위반이다.
